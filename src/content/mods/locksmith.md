**Locksmith** lets you lock containers so only the right key opens them.

## Locks and keys

- Add a lock to a container and it is locked with a **key code**. Only a **Key** with the matching code opens it.
- **Copy a key** by putting it in an anvil with iron.
- Hold the reveal key to see a key's code in its tooltip.
- **Golden Locks** are opened with **Golden Keys**.
- **Trial Locks** are opened with Trial Keys, the same keys that open vaults. Ominous Trial Keys open ominous vaults.
